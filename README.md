## Add an event · 添加活动

1. **Easiest:** [fill in the form](https://github.com/bovi/beijing-events/issues/new?template=new-event.yml). A pull request is created for you automatically.
   **最简单：** 填写表单即可，系统会自动创建 Pull Request。
2. **Or** copy [events/_template.yml](events/_template.yml) to `events/YYYY/YYYY-MM-DD-short-title.yml` and open a pull request.

The tables above are generated from the files in [events/](events/). Please don't edit them by hand.
上面的表格由 `events/` 目录自动生成，请勿手动修改。

## Calendar · 日历

Add `https://raw.githubusercontent.com/bovi/beijing-events/main/calendar/events.ics` to Google Calendar, Apple Calendar or Outlook ("add calendar from URL") to always see the latest events.

## Why this exists · 为什么创建这个项目

I created this repository because it was hard to get an overview of the tech events happening in Beijing. They are spread across WeChat groups, Meetup, 活动行 and company websites. This gives the community one place to find them and share them.

我创建这个项目，是因为很难全面了解北京正在举办的科技活动。活动信息分散在微信群、Meetup、活动行和各公司网站上。这里希望成为一个大家都能查找和分享活动的地方。
